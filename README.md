# 🧪 Lab Management Web App

A comprehensive web application designed to streamline and automate laboratory management processes. This system helps to easily manage equipment inventory, track chemical usage, and handle user access efficiently.

## 🚀 Core Features
- **Inventory Tracking:** Manage lab equipment, apparatus, and chemical stocks in real-time.
- **User Management:** Role-based access control for Admins, Instructors, and Students.
- **Resource Booking:** Schedule and reserve lab equipment for specific practical sessions.
- **Reporting & Analytics:** Generate detailed reports on inventory usage, damages, and shortages.
